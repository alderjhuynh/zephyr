GETTING STARTED
01

Install Fabric Loader for Minecraft 26.2 with the Fabric installer.

02

Install Fabric API for 26.2 from Modrinth or CurseForge.

03

Drop the Zephyr .jar into your .minecraft/mods folder and launch the Fabric profile.

04

Press L + Enter in-game to open the menu. Every bind is reconfigurable from the Keybinds screen.
